# Accretion signatures during supermassive black hole mergers  
## Description  
This repository was used to track and to manage and analyse all data for my Masters thesis with the University of Leeds. 
The project explores the dynamics of a circumprimary disc orbiting a supermassive black hole (SMBH) as a smaller SMBH spirals into 
the it on the gravitational-wave timescale. The question was if the 'snowplough effect', proposed in earlier papers, is a physical 
phenomenon or a numerical artefact. All data was collected using [PHANTOM SPH](https://github.com/danieljprice/phantom) by Daniel Price.
Repository includes analysis code and other Jupyter Notebooks/Python scripts to help understand the snowplough effect (eg finding the
decoupling separation).  
This project has been finished. The final report has been posted on my [Linkedin](https://www.linkedin.com/in/thomas-leon-shilling/)
for anyone curious about the final product.
